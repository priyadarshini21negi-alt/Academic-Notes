## Decoding Models 
### Decoding :-
A model that decodes a variable from neural activity can tell us _how much information_ a brain area contains about that variable. 

>Can you reconstruct what the mouse was seeing just from neurons? 
 If yes : The information must exist in those neurons  

```
You start with neurons:-
Neural Activity      
   ↓
Predict Stimulus


Example:- 
Neuron activity 
   ↓
Guess orientation
```

Question:
> What information is contained in the brain?

## Encoding Models 
An encoding model is a model that maps external variables (such as images, sounds, movements, or decisions) to neural responses.

Reverse direction.
```
Stimulus    
↓
Predict Neural Activity

Example:
45° grating 
↓
Predict neuron firing
```
Question:
> How does the brain represent information?
