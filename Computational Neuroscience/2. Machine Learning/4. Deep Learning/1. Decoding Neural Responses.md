## [[Decoding Models]] 
### Decoding :-
A model that decodes a variable from neural activity can tell us _how much information_ a brain area contains about that variable. 

>Can you reconstruct what the mouse was seeing just from neurons? 
 If yes : The information must exist in those neurons  

```
You start with neurons:-
Neural Activity      
   ↓
Predict Stimulus


Example:- 
Neuron activity 
   ↓
Guess orientation
```

Question:
> What information is contained in the brain?

#### Why Decoding works?
Different neurons have different tuning curves.  
Therefore, the population activity pattern contains information about stimulus orientation.  
If all neurons responded identically to every stimulus, decoding would be impossible.

## [[Tuning Curve]]
Average response of a neuron as a function of stimulus orientation.

***Purpose*** 
Shows which orientations a neuron prefers.
***Key Insight***:
Different neurons prefer different orientation
