### Q. Select all the even indexed rows from the given dataset. What is the value in the 3rd indexed column of the 0th indexed row in the selected dataframe. (row/ column indexed from zero(0) in python/pandas) 
#### Select all the even-indexed rows :-
`new_df = df.iloc[::2]`

How does `::2` work? 
Python slicing follows this pattern: `[start : stop : step]`
- `start` is omitted, so it starts at index 0.
- `stop` is omitted, so it goes to the end
- `step=2`, so it selects every row indices `0, 2, 4, 6, ....`

#### Get the value at row 0, column 3
`new_df.iloc[0,3]`

Shortest combination :-
`df.iloc[::2].iloc[0,3]`
