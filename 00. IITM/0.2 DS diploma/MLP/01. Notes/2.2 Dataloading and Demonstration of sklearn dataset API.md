
sklearn has three families of data functions, and the prefix tells you which one you’re using: 
1. `load_` - small bundled 
2. `fetch_` large, downloaded 
3. `make_` - synthetic 

Loaders and fetchers return a dictionary-like object with `.data` and `.target`.

Generators return a tuple `(X, y)` 

For everything else (CSV, images, audio), you use pandas, NumPy, SciPy, or skimage instead.

# Intuition 
In ML, you need data, and you need it in different situations:
- You want something small and standard to test an algorithm quicky. That's a *loader*.
- Bigger, realistic dataset too big to ship inside the lib. - that's *Fetcher* 
- Control the data itself, how noisy it is, how many feature matter, how many cluster exist. - *generator* - it builds fake data with properties you can choose 

You can’t tell if an algorithm works on real data if you’ve never tested it on data where you know the right answer. **Generators** give you that.

### What gets returned?
**Loaders and fetchers** return a **Bunch**, which behaves like a dictionary. The two keys that matter: 
- `data` - feature matrix of shape(n,m)
- `target` - label vector of shape (n,)
